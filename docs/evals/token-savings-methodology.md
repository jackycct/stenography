# Token-Savings Methodology

## Purpose

Define how Stenography measures token savings, missing-context failures, and task success.

Performance claims are measured only when backed by AgentLens artifacts. Without AgentLens output, numbers are targets or hypotheses.

## Baselines

Compare each Stenography pack against:

- raw issue + raw repo excerpts
- verbose hand-written context
- Codebrain output without Stenography packing

## Metrics

| Metric | Definition | Owner |
| --- | --- | --- |
| input tokens | tokens sent to the coding agent before task execution | AgentLens |
| output tokens | tokens generated by the coding agent | AgentLens |
| total tokens | input + output tokens | AgentLens |
| token savings | `(baseline_tokens - stenography_tokens) / baseline_tokens` | AgentLens |
| missing-context failures | task failures caused by omitted required context | reviewer + AgentLens |
| task success | pass/fail against issue acceptance criteria and validation commands | reviewer + CI |
| tool calls | count of shell/search/GitHub/tool invocations | AgentLens |
| elapsed time | wall-clock task time | AgentLens |
| cost per success | run cost divided by successful completion | AgentLens |

## Procedure

1. Select a task with stable acceptance criteria.
2. Capture baseline context and Stenography context.
3. Run equivalent coding-agent attempts.
4. Record validation commands and results.
5. Classify failures:
   - missing context
   - incorrect context
   - tool/environment failure
   - implementation error unrelated to pack
6. Attach AgentLens artifact links before publishing measured claims.

## Reporting Rules

- Use "target" or "hypothesis" for unmeasured numbers.
- Use "measured" only with an AgentLens artifact link.
- Include baseline type, task id, commit SHA, and validation command.
- Do not compare unrelated tasks as token-savings evidence.

## Minimum Eval Record

```json
{
  "task_id": "issue-123",
  "baseline": "raw_issue_plus_repo_excerpts",
  "stenography_pack": ".stenography/packs/issue-123.pack.md",
  "agentlens_artifact": null,
  "validation": "npm test",
  "result": "hypothesis_only"
}
```
